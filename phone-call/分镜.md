# 分镜：打电话时，你的声音是怎么跑到对方耳朵里的？

- 规格：1920×1080，30fps，45.0 秒（1350 帧）
- 配音：没有 MiniMax Key，不跑 TTS。底部字幕来自批准的解说，每条不超过 20 字
- 音乐：套件自带 CC0 `bgm.mp3`（Outer Space Loop / wipics）
- 画面只使用 `tokens.ts`。数字、光脉冲都标成原理示意

| 屏 | 时段 | 画面 | 屏幕上的字 | 字幕 |
|---|---|---|---|---|
| S1 | 0–5 秒 | 两部手机隔一条距离弧，近处只有说话的声波记号，远处是问号 | 你的声音，怎么过去的？ | 隔着几千公里打电话 / 对方怎么能听见你 |
| S2 | 5–10 秒 | 声波记号沿电线走到另一部手机，大小不变；然后整段打红叉 | 先写出错误模型「声波沿线传到远方」，再改成「传过去的不是声音 / 是信号」 | 不是声音顺着线跑 / 传过去的其实是信号 |
| S3 | 10–18 秒 | 空气微粒在各自竖线附近来回，疏密向话筒传；话筒后面画出连续电压 | 振动 → 电信号 | 空气微粒只在原地振动 / 话筒把振动变成电压 / 出来是连续起伏的电信号 |
| S4 | 18–33 秒 | 采样点、量化台阶、数据包分开画；手机用无线电到近处基站，基站之间用光纤光脉冲 | 波形 → 数字 → 基站 → 光纤网络 | 先按时间取下一串样点 / 再把高低量化成格子 / 编码压缩打成数据包 / 无线电只发到附近基站 / 光纤里走的是光信号 |
| S5 | 33–39 秒 | 左边只画座机到墙插的短线，里面是连续电流；右边手机是数据包 | 老座机：连续电流 / 手机：数字 | 老座机这一段可以是电流 / 长途网不是整段都这样 |
| S6 | 39–45 秒 | 对方基站无线电到手机，数据包展开成台阶再变成电压，推动扬声器 | 数字 → 声音 | 数字还原成电信号 / 扬声器振动，声音回来 |

## 科学边界

- 主线是现代手机通话。2G/3G 电路交换、网络电话、跨运营商中转都没展开。
- 骨干网写的是「多为光纤」。光纤里是代表数字的光脉冲，不是声波，也不是 0 和 1 在飞。
- 两部手机不直接相连，中间经过各自附近的基站。
- 采样和量化分开画，不写采样率、码率。
- 老座机只示意「这一段可以用连续电流」，不表示整张长途网都是连续电流。
- 第 2 屏划掉的是「声波沿线运到远方」这个模型。声波记号大小不变，衰减不是被否定的理由。
